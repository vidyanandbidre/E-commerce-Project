# E-Commerce Project

This is the **E-Commerce Project** that aims to provide an online platform for users to browse and purchase products. The project is designed using **microservices architecture**, and it contains multiple services such as the User Service, Product Service, and Order Service, among others.

## Project Structure

The project follows a modular approach, and each service is developed as a separate module with its own repository. Below is the description of the services in the project:

### 1. **User Service**
The User Service handles all user-related functionality, including:
- User registration
- User authentication
- User profile management

### 2. **Product Service**
The Product Service manages the products available in the e-commerce platform, allowing:
- Product catalog display
- Product details retrieval
- Managing product stock

### 3. **Order Service**
The Order Service handles the ordering process, which includes:
- Order creation
- Order tracking
- Order history
